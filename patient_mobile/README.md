# Patient Mobile App

This Flutter app is a mobile client for the patient-facing portions of the mental health backend.

## Setup

1. Install Flutter SDK
2. Run `flutter pub get`
3. Run `flutter run` on an emulator or device

## Notes

- The backend base URL is configured in `lib/services/api_service.dart`.
- Replace `http://10.0.2.2:5000` with your API URL if needed.
